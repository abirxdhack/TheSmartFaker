Installation
============

Requirements
------------

- Python 3.8 or higher
- ``pycountry``

Install from PyPI
-----------------

.. code-block:: bash

    pip install smartfaker

Install from source
-------------------

.. code-block:: bash

    git clone https://github.com/ISmartCoder/smartfaker
    cd smartfaker
    pip install -e .

Verify installation
-------------------

.. code-block:: python

    import smartfaker
    print(smartfaker.__version__)
