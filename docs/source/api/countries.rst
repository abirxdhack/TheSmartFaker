Supported Countries
===================

SmartFaker ships bundled address data and IBAN generators for the countries
listed below. The tables are regenerated automatically by the docs compiler
from the live ``smartfaker/data/`` directory and the
:data:`smartfaker.iban.COUNTRY_GENERATORS` registry.
